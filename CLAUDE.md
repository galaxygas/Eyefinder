# Eyefinder

Read and follow the project guide before making changes:

@AGENTS.md

Essentials:
* Work on an `agent/<topic>` branch and open a pull request; never push to `main`.
* Never guess a format: cite the source, or leave it at `SupportLevel::DetectedOnly`.
* Run `cargo fmt --all`, `cargo clippy --workspace --all-targets -- -D warnings` and `cargo test --workspace` before opening the pull request.
