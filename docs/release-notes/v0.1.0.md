Released 2026-10-21.

The first release of Eyefinder, a viewer and extractor for the assets of GTA III, Vice City and
San Andreas (the classic games, not the Definitive Edition). This release covers **audio**.

## What it does
* Open a PC game folder, an extracted disc or a PS2 `.iso`. The game and platform are detected, and the files used as evidence are shown.
* Browse every radio station, cutscene, mission line, sound effect bank and movie soundtrack, grouped by category and searchable.
* Play any item with a waveform, sample-exact seeking and volume control.
* Export lossless WAV:
  * PCM is copied bit for bit.
  * ADPCM is decoded exactly.
  * MP3/MP2/Vorbis are decoded to 32-bit float.
  * Nothing is resampled.
* Every export comes with `manifest.json`, `manifest.csv` and `tracklist.txt`, plus marker splits, `.cue` sheets, Audacity labels, SFX loop points and San Andreas beat data.
* `eyefinder-cli` does the same from the command line (`info`, `list`, `export`).

## Support levels
| | PC | PS2 |
|---|---|---|
| GTA III | Verified | Implemented from spec (streams) |
| Vice City | Implemented from spec | Implemented from spec (streams) |
| San Andreas | Implemented from spec (streams and SFX) | Not supported yet |

* **Verified** means checked against real game files.
* **Implemented from spec** means built from documented reverse-engineering sources and tested against synthetic files, but not yet confirmed on a real copy.
* Xbox, mobile and Mac data is recognised but not decoded.

Details and sources: [docs/SUPPORT.md](https://github.com/galaxygas/Eyefinder/blob/main/docs/SUPPORT.md).

If you own one of these games, a [format report](https://github.com/galaxygas/Eyefinder/blob/main/CONTRIBUTING.md#reporting-a-format-result) helps move it to Verified.
