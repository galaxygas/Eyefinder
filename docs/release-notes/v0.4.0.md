Released 2026-10-24.

Eyefinder 0.4 adds a **build database** of every documented GTA build and version, which you can edit and update without a new app release. It also adds **Export Map files** for every game whose map formats are known, and shows **support per platform** on the Index.

## New
* **Build database** (Index page):
  * 1,954 entries for 23 games and groups, with 194 sections of history and notes and 935 cited sources. They cover retail releases, reissues, patches, title updates, digital and mobile versions, demos, regional and rating editions, and preserved dumps.
  * It is imported from the maintainer's research file. A test checks that every table row, heading and source of that file is in the database.
  * Entries are grouped by game, platform and kind. Each shows its version, region, date, serials, confidence, notes and source links.
  * **Edit in the app:** add an entry, edit or hide any entry, and revert your changes. Edits are saved as TOML files in your profile and survive updates.
  * **Update without a new release:** **Database → Import database file…** takes a `.toml` file or a database pack (`.zip`). **Check for a database update** downloads the newest `db-*` pack from GitHub and checks its SHA-256. **Export my additions…** saves your entries so you can contribute them.
  * The files are plain TOML in `crates/ef-core/data/database`. [docs/DATABASE.md](https://github.com/galaxygas/Eyefinder/blob/main/docs/DATABASE.md) explains how to add or correct an entry.
  * Command line: `db info`, `db validate`, `db export`, `db import`, `db pack`, `db update`.
* **Export Map files** (button in the game header; `eyefinder-cli maps`). Choose any of:
  * **Raw files:** a byte-for-byte copy of every map file, including entries inside IMG archives.
  * **Individual files:** JSON for map data and PNG for radar tiles.
  * **Full maps:**
    * **GTA1, London 1969, London 1961 and GTA2:** the whole city top-down at the games' native 64 pixels per block, as one PNG and optional tiles. You also get `map.json` (blocks, columns, objects, zones, lights) and an `overlay.svg`. GTA2 is supported on PC and Dreamcast.
    * **GTA III, Vice City and San Andreas:** the radar map assembled from the radar tiles. Vice City and San Andreas also get their pause-menu map; GTA III on PC has none.
    * **GTA III, Vice City and San Andreas on PC:** the whole placed world as a 3D glTF 2.0 scene with textures, grouped by area and level of detail. You also get a textured top-down render (0.5–4 pixels per world unit) and `world.json` with every model, instance and matrix.
  * Each export writes a manifest that lists the sources and the support level of each file.
* **Support per platform on the Index:** each platform section shows Eyefinder's support for that platform, so GTA III no longer shows "Verified" under Android. Platforms Eyefinder does not read say so.

## Support levels
| | PC | PS2 | Xbox | Dreamcast |
|---|---|---|---|---|
| GTA1 / London maps (CMP) | From spec | | | |
| GTA2 maps (GMP) | From spec | | | From spec |
| GTA III, VC, SA raw map files, radar and pause-menu maps | From spec | From spec | From spec | |
| GTA III, VC, SA 3D scene and top-down render | From spec | Not yet | Not yet | |

The audio and texture levels are unchanged from 0.3. The map readers are checked against synthetic fixtures, an independent Python reference and the Khronos glTF validator. They stay "from spec" until someone confirms them on real files. Not yet supported:
* console (PS2 and Xbox) model geometry for the 3D scene;
* collision (COL) as meshes; COL files are exported raw;
* maps of the PlayStation, Game Boy Color and Game Boy Advance releases, whose map formats are undocumented.

Details and sources: [docs/SUPPORT.md](https://github.com/galaxygas/Eyefinder/blob/main/docs/SUPPORT.md) and [docs/FORMATS.md](https://github.com/galaxygas/Eyefinder/blob/main/docs/FORMATS.md).

If you own one of these games, a [format report](https://github.com/galaxygas/Eyefinder/blob/main/CONTRIBUTING.md#reporting-a-format-result) helps move a format to Verified.
