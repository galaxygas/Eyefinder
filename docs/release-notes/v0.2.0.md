Released 2026-10-21.

Eyefinder 0.2 adds **textures**, version selection, a search for installed copies, a file tree and a new look.

## New
* **Textures:**
  * Every texture dictionary (`.txd`) in the game folder and inside IMG archives: GTA III/Vice City `.img` + `.dir`, and San Andreas `VER2`.
  * Supported natives: Direct3D 8 and 9 (PC), Xbox and PS2, covering 16- and 32-bit colour, luminance, 8- and 4-bit palettes, DXT1/3/5, swizzled PS2 and Xbox data, and every mip level.
  * Browse them as a thumbnail grid or a list, and preview them large with zoom, mip levels and a transparency checkerboard.
  * Export them as PNG, optionally every mip level, with DXT textures also kept untouched as `.dds`, plus `manifest.json` and `manifest.csv`.
* **Choose the game, platform and version** when adding a copy. Eyefinder detects them and shows its evidence:
  * the executable version on PC (1.0, 1.1/1.01, Steam and the San Andreas variants);
  * the disc serial on PS2.

  The choice is remembered and recorded in every export manifest. Right-click a game to change it later.
* **Find installed games:** looks through Steam libraries and, on Windows, the setup registry entries and the Rockstar Games folders. You can add one or all of the copies it finds.
* **Sidebar:** collapsible sections per asset type, and a **file tree** switch.
  * IMG archives open like folders.
  * Any file can be inspected (type, size, first bytes) and copied byte for byte.
* **New look:** near-black greys with a yellow accent, plus a light theme. Every text colour meets WCAG AA contrast.
* **Command line:** `scan`, `versions`, `textures`, and `--game` / `--platform` / `--version`.

## Support levels
| | PC | PS2 | Xbox |
|---|---|---|---|
| GTA III audio | Verified | From spec (streams) | Recognised only |
| Vice City audio | From spec | From spec (streams) | Recognised only |
| San Andreas audio | From spec (streams and SFX) | Recognised only | Recognised only |
| Textures (all three games) | From spec | From spec | From spec |

Textures are checked against librw, an exact specification decoder and Pillow on synthetic files; they have not yet been confirmed on real game files. Details and sources: [docs/SUPPORT.md](https://github.com/galaxygas/Eyefinder/blob/main/docs/SUPPORT.md) and [docs/FORMATS.md](https://github.com/galaxygas/Eyefinder/blob/main/docs/FORMATS.md).

If you own one of these games, a [format report](https://github.com/galaxygas/Eyefinder/blob/main/CONTRIBUTING.md#reporting-a-format-result) helps move a format to Verified.
